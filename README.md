# How does Ansdale feel today?

**《女巫小姐，森林和她的杂货店》** · 安斯戴尔与梦想乡的日常物语

## 简介

被埃尔大结界与外界隔开的一片乐园——梦想乡。

神眷森林深处，开着一间不起眼的杂货店，店主是黑白女巫安斯戴尔。妖精抱着大鱼来换魔药，人类村民放下一筐农作物就走，神社的巫女偶尔来讨一瓶"能喝出肉汁味道"的魔药……店里的日子缓慢又安静，像落在书页上的一小块阳光。

《女巫小姐，森林和她的杂货店》是一部以感官书写与角色心理见长的日常幻想小说。后续章节将陆续更新至本仓库。

该作品本身受东方project所启发，看作是东方二创或者其他的什么，请随意，但作为作者本人，或许更倾向于东方project二创的说法。
